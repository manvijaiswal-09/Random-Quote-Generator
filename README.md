# 📜 Random Quote Generator

A simple and responsive Random Quote Generator built using HTML, CSS, and JavaScript. Click the button to display a new inspirational quote instantly.

## 🚀 Features

- 🎯 Generates a random quote on button click
- 📱 Responsive design
- ⚡ Fast and lightweight
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Random-Quote-Generator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## 💡 How It Works

1. A list of quotes is stored in a JavaScript array.
2. When the user clicks the **Random Quote Generator** button, a random index is generated.
3. The corresponding quote is displayed on the screen.
